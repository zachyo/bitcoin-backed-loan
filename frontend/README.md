# Frontend for Bitcoin-backed Loan

This folder will contain the frontend app for the Bitcoin-backed loan project.

Planned contents:
- React/Next or Vite app
- Wallet/connect integration for signing transactions
- UI for deposit, borrow, repay, withdraw, and liquidation flows
- Integration tests and CI pipeline

To get started locally (example with Vite + React):

1. cd frontend
2. npm install
3. npm run dev

See `ISSUES.md` for planned frontend work items.
